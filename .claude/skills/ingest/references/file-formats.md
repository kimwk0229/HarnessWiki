# 파일 형식 및 링크 규칙

## 1. 원본 저장 (raw/)

### 디렉토리 구조
```
raw/
├── YYYY-MM-DD_슬러그/
│   ├── raw.md      # 원문 그대로 (수정 금지)
│   └── meta.md     # 메타카드 (요약, 참석자, 링크)
```

### raw.md 예시

**파일**: `raw/2026-08-10_제품주간회의/raw.md`

```yaml
---
title: 2026-08-10 제품 주간회의
date: 2026-08-10
type: 주간회의
participants:
  - 박준서
  - 강태우
  - 최민아
---

## 논의 내용

### 결제 연동 진행상황
박준서 담당:
- 8월 중순 목표 확정
- 결제수단 우선순위: 신용카드 → 은행이체 → 기타
- 5/25 테스트 계정 이슈 재검토 중

강태우 에스컬레이션:
- 엔터프라이즈 고객 A/B/C와 계약 조건 논의
- 8월 완료 필수

### 정산 주기
...

## 결정사항

- 결제 연동: 8월 중순 완료 목표
- 정산 주기: 고객사B 요청(주 1회) 재보류

## 액션아이템

- [ ] 박준서: 결제 API 개발 (8월 15일)
- [ ] 강태우: 고객 계약서 최종 검토 (8월 10일)
```

**rule**: 저장 후 절대 수정 금지. 원문 그대로 유지.

- **원본**: [raw.md](raw.md)

결제 연동 8월 중순 완료 목표 확정, 정산 주기 재보류.

## 2. 주제 페이지 (wiki/topics/)

### 폴더 노트 구조

```
wiki/topics/
├── 결제-연동/
│   └── 결제-연동.md
├── 정산-주기/
│   └── 정산-주기.md
├── 온보딩-개선/
│   └── 온보딩-개선.md
```

**rule**: 폴더 이름 = 파일 이름 = 슬러그 (kebab-case)

### 주제 페이지 구조

**파일**: `wiki/topics/결제-연동/결제-연동.md`

```yaml
---
updated: 2026-08-10
---

# 결제-연동 (Payment Integration)

- 담당: 박준서
- 상태: 진행 중

엔터프라이즈 고객 3곳과의 계약 조건:
- 신용카드 연동 필수
- 자동 정산 기능
- 영수증 발급

## 결정사항

- 8월 중순 완료 목표 확정
- 결제수단 우선순위: 신용카드 > 은행이체 > 기타
- 에스컬레이션: 강태우가 고객 계약서 최종 검토 (8월 10일)
출처: [2026-08-10 제품 주간회의](../../../raw/2026-08-10_제품주간회의/meta.md)

### 2026-07-23
- 목표 유지 (8월 중순)
- 개발 착수 승인

### 2026-07-09
- 결제수단 우선순위 결정
- 테스트 계정 이슈 조사 필요

## 고려사항 & 이슈

### 테스트 계정
- 5/25부터 테스트 계정 인증 오류 발생
- 원인: [확인 중]
- 해결책: [대기 중]

### 고객 요청사항
- 고객 A: 신용카드 외 은행이체도 필요
- 고객 B: 월급날 자동 정산 요청
- 고객 C: API 직접 연동 요청

## 액션아이템

- [ ] 박준서: 결제 API 개발 (8월 15일)
- [ ] 강태우: 고객 계약서 최종 검토 (8월 10일)

## 관련 페이지

- [로드맵](../로드맵/로드맵.md) — Q2 최우선 목표
- [정산-주기](../정산-주기/정산-주기.md) — 결제 연동 완료 후 필수 진행
- [대시보드-개편](../대시보드-개편/대시보드-개편.md) — 별도 프로젝트
```

**핵심 원칙**:
- **현황/개요**: 최신 상태로 갱신 가능
- **결정사항**: 날짜별 블록, append-only (기존 블록 수정 금지)
- **근거 링크**: 모든 정보에 출처 회의 meta.md 링크
- **frontmatter**: `updated: YYYY-MM-DD` 필드 포함 (권장)

## 4. 롤업 페이지 (decisions.md, action-items.md)

### decisions.md 구조

**파일**: `wiki/decisions/decisions.md`

```markdown
# 결정사항 롤업 (Decisions)

## 2026-08-10 제품 주간회의

- [8월 중순 완료 목표 확정](../topics/결제-연동/결제-연동.md) — 결제 연동
- [강태우 에스컬레이션](../topics/결제-연동/결제-연동.md) — 고객 계약서 최종 검토

## 2026-07-23 제품 주간회의

- [온보딩 개선 프로젝트 종료](../topics/온보딩-개선/온보딩-개선.md)
```

**rule**: 
- 각 회의마다 `## YYYY-MM-DD 회의명` 섹션
- 불릿으로 결정사항 나열
- 각 항목은 해당 토픽 페이지로 링크
- append-only (기존 섹션 수정 금지)

### action-items.md 구조

**파일**: `wiki/action-items/action-items.md`

```markdown
# 액션아이템 (Action Items)

## 2026-08-10 제품 주간회의

- [ ] 박준서: 결제 API 개발 (8월 15일) — 출처: [2026-08-10 제품 주간회의](../../raw/2026-08-10_제품주간회의/meta.md)
- [ ] 강태우: 고객 계약서 최종 검토 (8월 10일)

## 2026-07-23 제품 주간회의

- [x] 최민아: A/B 테스트 결과 정리 — 완료
```

**rule**:
- 각 회의마다 `## YYYY-MM-DD 회의명` 섹션
- 미완료: `- [ ]`, 완료: `- [x]`
- 담당자/기한은 자유 형식 (강제 아님)
- append-only (기존 섹션 수정 금지)

## 6. 로그 (log.md)

**파일**: `D:\HarnessWiki\log.md`

```markdown
# 변경 로그

## 2026-08-10

- [INGEST] 2026-08-10 제품 주간회의 적재 완료. 갱신: 결제-연동(완료 목표 확정), 정산-주기(재보류). decisions.md/action-items.md 갱신.
- [INGEST] 2026-07-23 제품 주간회의 적재 완료. 갱신: 온보딩-개선(프로젝트 종료, 42%→27%), 결제-연동(목표 8월중순 확정).
```

**rule**:
- 최신이 위 (역순)
- `[INGEST]` 태그로 시작
- 날짜 명시
- 생성/갱신 파일 목록 포함
- 간단한 요약
