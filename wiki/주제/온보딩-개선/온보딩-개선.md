# 온보딩-개선 (Onboarding Improvement)

신규 사용자 온보딩 프로세스 개선.

## 현황

**2026-06-25 기준 (최신):**
- 상태: 진행 중 (B안 채택 - 항목 축소)
- 우선순위: 높음 (3단계 42% 이탈 발견으로 Q2 추진으로 변경)
- 결정: B안(필수 항목 7개 → 3개 축소) 채택, 7/1 배포 예정
- 분석 완료: 3단계(결제 정보 입력)에서 42% 이탈 발견

## 개요

사용자 이탈 문제 개선을 위한 온보딩 프로세스 고도화.
Q2에는 결제 연동을 우선했으나, 온보딩 3단계 42% 이탈 발견으로 즉시 진행으로 변경.
A/B 테스트를 통해 개선안 검증 진행.

## 결정사항

### 2026-06-25 (최신)
- **B안 채택 (항목 축소만 먼저 진행)**
  - A안(결제 요청을 뒤로): 이탈은 줄지만 실제 매출로 미이어짐 (결정: 부결)
  - B안(입력 단계 단순화): 필수 항목 7개 → 3개 축소 + 2차에 카드 스캔 기능
  - 근거: 근본적 해결이 필요하며, 항목 축소는 3일이면 가능
- **배포 일정**: 7월 1일 배포, 2주간 측정
