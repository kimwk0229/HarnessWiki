# 온보딩 개선 (Onboarding Improvement)

## 현황
**상태**: 완료/종료 ✅  
**최종 결과**: 이탈률 **42% → 27%**, 가입완료율 **18% 상승**

## 개요
신규 사용자 온보딩 프로세스 개선. 초기에는 로드맵상 Q3 계획이었으나, 
CS 피드백으로 심각한 이탈 문제 발굴.

## 의사결정 이력

### 2026-07-23 — 프로젝트 종료 (최신)
- **A/B 최종 결과**:
  - 3단계 이탈률: **42% → 27%** ✅ (15% 개선)
  - 전체 가입완료율: **18% 상승** ✅
  - 결제 미등록 유저: 증가 없음 (A안 우려 불식)
- **결정**: B안 전면 적용. 온보딩 개선 건 종료
- **향후**: 카드 스캔(2차) 기능은 Q4로 이연
- 출처: [2026-07-23 제품 주간회의](../../../raw/2026-07-23_제품주간회의/meta.md)

### 2026-07-09 — A/B 진행 상황 보고
- **배포 완료**: 7월 1일 B안(항목 축소) 배포 완료
- **데이터 수집**: 1주차 데이터 수집 중
- **초기 지표**: 긍정적 (최종 결과는 다음 회의에서)
- 출처: [2026-07-09 제품 주간회의](../../../raw/2026-07-09_제품주간회의/meta.md)

### 2026-06-25 — B안 채택 (1차 항목 축소)
- **A/B안 비교**:
  - A안: 결제 정보 입력을 뒤로 미룸 (이탈률 감소하나 실제 매출 연결 불명확, 결제 미등록 유저 증가 우려)
  - B안: 필수 항목 축소(7개→3개) + 카드 스캔 기능 추가 (근본적 개선)
- **결정**: B안 채택. 1차는 항목 축소만 진행, 카드 스캔(2차)은 나중
- **일정**: 7월 1일 배포, 2주간 측정
- 출처: [2026-06-25 온보딩 개선 회의](../../../raw/2026-06-25_온보딩개선회의/meta.md)

### 2026-06-11 — 분석 완료 & A/B 테스트 결정
- **분석 결과**: 3단계(결제 정보 입력)에서 **42% 이탈** ⚠️
  - 다른 구간: 10% 내외 (정상)
  - 명확한 병목 지점 확인
- **개선 방안**: A/B 테스트로 2개 안 검증 예정
  - A안: 결제 정보 입력을 뒤로 미룸 (이탈 감소하나 실제 전환 미지수)
  - B안: 입력 단계 자체를 단순화 (필수 7개 → 3개, 카드 스캔 기능)
- **결정**: A/B 테스트 진행하여 더 나은 방안 선택
- 출처: [2026-06-11 제품 주간회의](../../../raw/2026-06-11_제품주간회의/meta.md)

### 2026-05-14 — 문제 발굴
- 신규 가입자 온보딩에서 이탈이 심하다는 CS 피드백 지속
- 정확한 수치는 아직 없음. 구간별로 봐야 할 듯
- 로드맵상 후순위이지만 데이터는 봐두자
- 출처: [2026-05-14 제품 주간회의](../../../raw/2026-05-14_제품주간회의/meta.md)

### 2026-04-16 — 초기 계획
- **일정**: Q3로 이연 (Q2는 결제 연동 우선)
- Q2 로드맵: 결제 연동만 진행, 온보딩/대시보드 개편은 후순위
