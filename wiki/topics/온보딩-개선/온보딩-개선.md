# 온보딩 개선 (Onboarding Improvement)

## 현황
**상태**: 진행 중 (A/B 테스트 완료 → 전면 적용)  
**핵심 이슈**: 3단계(결제정보입력)에서 42% 이탈

## 개요
신규 사용자 온보딩 프로세스 개선. 초기에는 로드맵상 후순위였으나, 
CS 피드백으로 심각한 이탈 문제 발굴 후 우선순위 상향.

## 의사결정 이력

### 2026-05-14 — 문제 발굴
- 신규 가입자 온보딩에서 이탈이 심하다는 CS 피드백 지속
- 정확한 수치 분석 필요성 인식
- 출처: [2026-05-14 제품 주간회의](../../../sources/2026-05-14-제품주간회의/meta.md)

### 2026-06-11 — 이탈률 분석 완료
- **3단계(결제정보입력)에서 42% 이탈** (다른 구간은 10% 내외)
- A/B 테스트로 개선안 검증하기로 결정
- 출처: [2026-06-11 제품 주간회의](../../../sources/2026-06-11-제품주간회의/meta.md)

### 2026-06-25 — 개선안 최종 결정
- **B안 채택**: 필수항목 7개 → 3개로 축소 (근본적 해결)
- A안(입력 지연)은 지표는 좋아지지만 실제 매출로 이어지지 않을 수 있음
- **배포**: 2026-07-01, 2주간 측정
- 출처: [2026-06-25 온보딩 개선 회의](../../../sources/2026-06-25-온보딩개선회의/meta.md)

### 2026-07-23 — A/B 테스트 성공 → 전면 적용
- **결과**: 3단계 이탈률 42% → 27% (감소)
- **전체 가입 완료율**: 18% 상승
- **결제 미등록 유저**: 증가 없음 (A안 우려사항 해소)
- **결정**: B안 전면 적용, 온보딩 개선 건 종료
- 카드 스캔 기능(2차): Q4로 미룸
- 출처: [2026-07-23 제품 주간회의](../../../sources/2026-07-23-제품주간회의/meta.md)

### 2026-04-16 — 초기 계획
- **일정**: Q3로 이연 (Q2는 결제 연동 우선)
- Q2 로드맵: 결제 연동만 진행, 온보딩/대시보드 개편은 후순위
- 출처: [2026-04-16 제품 주간회의](../../../sources/2026-04-16-제품주간회의/meta.md)
